# JsAst

This is a minimal JavaScript syntax tree carved out of the
[JsCert](https://github.com/jscert/jscert) project.

## Installation

JsAst depends on:
- Rocq (version 9.1.0) or later

### From opam

```
opam repo add rocq-released https://rocq-prover.org/opam/released
opam install rocq-jsast
```

### Local with opam

In this directory:

```
opam install .
```

### From source

To compile, do:
```
make
```

To install as a Rocq user contribution, do:
```
make install
```
